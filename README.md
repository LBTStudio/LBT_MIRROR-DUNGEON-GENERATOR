# ORBITAL ROUTE ATLAS

**ORBITAL ROUTE ATLAS** は、TRPG用の一方向移動ツリーを作成し、SVGまたはPNGで保存できる静的Webツールです。始点からの列数と各列の地点数を設定し、地図上の地点を直接選択して内容を編集できます。

> このツールは、一般的な「地点から次の地点を選ぶ」移動構造を扱います。特定作品の画面・ロゴ・固有アイコン・用語・画像は利用していません。視覚設計上の区別の方針は [`design-distinction.md`](./design-distinction.md) を参照してください。

## 利用方法

公開サイトでは、まず **列数** で始点からどこまで進めるかを決め、各列の **地点数** を `− / ＋` で調整します。地点の種別・名称・縁取りは、**地図上のアイコンを直接クリックまたはタップして選択**してから、編集レールの「選択中の地点」で変更します。地点一覧や列内プルダウンを常時操作する必要はありません。

経路は左から右へ自動接続されます。上段の地点は次列の上段・中央、中央の地点は次列の全段、下段の地点は次列の中央・下段へ進むため、不要な対角交差を抑えながら分岐と合流を表せます。モバイルでは選択した地点を自動で中央に拡大表示し、`選択地点表示 / − / 全体表示 / ＋`で確認できます。

設定はブラウザー内に自動保存されます。上部の **設定を保存** でJSONとして書き出し、**設定を読む** で読み戻せます。完成した移動図はSVGまたはPNGで保存できます。

## GitHub Pagesでの公開

このリポジトリでは、`main`への更新時にGitHub Actionsが静的ファイルを生成し、GitHub Pagesへ配布します。公開URLは `https://lbtstudio.github.io/LBT_MIRROR-DUNGEON-GENERATOR/` です。

静的配布用のビルドは次のとおりです。

```bash
pnpm install --frozen-lockfile
pnpm build:pages
```

成果物は `dist/public/` に生成されます。GitHub Pagesではこの成果物だけを配布し、サーバー側の処理や秘密情報は使いません。

## 開発

```bash
pnpm install
pnpm dev
pnpm check
pnpm build
```
