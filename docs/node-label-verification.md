# 個別マス表示名の検証記録

## 仕様

選択中の各マスは「このマスの表示名」から24文字までの任意名を設定できる。未入力時は、現在のマス種別名を表示する。種類を変更したときも、独自に入力した名称は保持され、未入力または従来の種別名だけだった場合は新しい種別名を表示する。

表示名はマップのラベル、選択中マスのプロパティ見出し、接続先の一覧、JSONセーブ、PNG／JPEG／GIF／APNGで共通して扱う。画像出力は表示中のSVGをもとにするため、ラベル表示が有効なら全形式に同じ表記が反映される。

## 実画面検証

| 観点 | 結果 |
| --- | --- |
| PC入力 | 一般戦闘マスへ`左ルート・通常戦闘`を入力し、マップ上のラベル、プロパティ見出し、接続一覧に即時反映された。 |
| 種類名フォールバック | 「種類名」ボタンで入力を空にすると、見出し・マップ表示が`一般戦闘`へ戻った。 |
| JSONセーブ | 実出力した`kagami-map (2).json`に`"label": "左ルート・通常戦闘"`が含まれることを確認した。 |
| PNG出力 | カスタム表示名を設定した状態で、テーマ背景・2×PNGを実出力し、保存完了通知を確認した。 |
| 390px相当 | 入力欄は284×33px、種類名リセットは54×32pxとして同居し、横オーバーフローなし。`node-label-mobile.png`で入力済み状態を確認した。 |
| 回帰 | GIF／APNG、背景自由変形、背景読込、個別表示名の構造テストを含む全21件が成功した。 |
